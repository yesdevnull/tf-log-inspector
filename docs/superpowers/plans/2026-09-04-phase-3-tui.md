# Phase 3: The TUI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the model layer browsable — three panes, four views, cumulative facet filtering, and a raw log view you can jump into from any span.

**Architecture:** A new `internal/tui` package holds a bubbletea `Model` over `*model.Log`. `Update` is a pure state transition and `View` returns a string, so the whole interface is tested without a terminal: table-driven tests for state, golden files at three widths for rendering. Nothing below `internal/tui` learns that a terminal exists.

**Tech Stack:** Go 1.25, bubbletea v1.3.10, lipgloss. These are the project's first third-party dependencies and they are confined to `internal/tui`.

**Spec:** `docs/superpowers/specs/2026-09-03-tf-log-inspector-design.md` — read *Views and interaction* (layout, the view table, keys, width degradation), *The observer effect*, *Architecture* (the dependency decision recorded 2026-09-04), and *Testing*.

## Critical context an implementer will not guess

**1. Every duration this UI renders was measured under logging.** Four captures of one workspace: 24.1s unlogged, 522.2s with debug plus provider TRACE — roughly 20× — because Terraform re-logs each line of a provider's stderr through its own logger. Rankings within a log hold, since every span paid the same cost; absolute times do not transfer to an unlogged run, and cross-provider comparison is the least reliable reading. `--profile` already prints this caveat and the TUI must carry an equivalent. A timeline reading "116 seconds" otherwise invites optimising time that does not exist. See *The observer effect* in the spec.

**2. The two span slices sit on different clocks.** `model.Log.RPCSpans` and `UISpans` are kept apart deliberately. `span.Span.StartMs`/`EndMs` are offsets from a per-builder zero point — read the doc comment on `span.Span`. **Never concatenate them**, never sort or compare across them by `StartMs`/`EndMs`. `DurationMs` is safe across builders. `model.PackLanes` and `model.PeakConcurrency` both return `model.ErrMixedTimelines` if handed a mixed slice; surface that error rather than ignoring it.

**3. UI-hook durations are whole seconds, ±1s each.** Terraform rounds both endpoints before subtracting. Any view ranking UI-hook spans must say so on screen, as `--profile` does.

**4. Resource addresses are unmasked.** The TUI is a local tool like `--profile`, not a shareable report like `--diagnose`. Show real addresses; do not import `internal/diagnose`'s masking. But the raw log view puts *arbitrary log content* on screen, which is a stronger disclosure surface than anything shipped so far — a screenshot of it carries whatever the log carries. That is expected and correct for a local tool; it is called out so nobody "helpfully" adds masking to the TUI or, worse, routes TUI content into a diagnose report.
